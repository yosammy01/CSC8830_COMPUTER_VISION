# Computer Vision - Module 2: Camera Calibration and Real-World Dimensions

This repository contains two scripts used for camera calibration and determining the real-world 2D dimensions of objects.

## 1. Camera Calibration (`calibration_code.py`)

This script processes a set of images containing a checkerboard pattern to calibrate the camera and calculate its intrinsic matrix and distortion coefficients. 

### How to execute:
1. Place your calibration images (checkerboard photos) in the `images/` directory.
2. Run the script using Python:
   ```bash
   python calibration_code.py
   ```
3. The script will output a `calibration_params.json` file containing the camera matrix and distortion coefficients, and a `calibration_output.txt` with a log of the process.

## 2. Real-World 2D Dimensions (`get_real_world_2d_dimensions_code.py`)

This script uses the calibration data from the previous step to undistort images and calculate the real-world dimensions (width and height in millimeters) of objects based on a known Z-distance.

### How to execute:
1. Ensure that `calibration_params.json` (generated by the calibration script) exists in the same directory.
2. Place your target images (e.g., photos of objects on a white background) in the `measurements/` directory.
3. Run the script using Python:
   ```bash
   python get_real_world_2d_dimensions_code.py
   ```
4. The script will process each image, outputting the dimensions to the terminal and saving a log to `dimensions_output.txt`. It will also display a visual representation of the detected object; press any key to advance to the next image.
